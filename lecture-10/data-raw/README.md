# Упражнение: ETL върху цените на горивата

Тази папка съдържа **сурови данни**, така както реално пристигат — в три различни файла с различни формати. Задачата ви е да ги превърнете в **една чиста, готова за анализ таблица** чрез процеса **Extract → Transform → Load**.

> Източник на числата: Седмичен петролен бюлетин на Европейската комисия (Weekly Oil Bulletin), България, 2023–2025.

## Файлове

| Файл | Какво е | Известни проблеми (нарочно) |
|------|---------|------------------------------|
| `fuel_2023_raw.csv` | Седмични цени 2023 | 4 реда боклук отгоре; криптични имена на колони; десетична **запетая**; дати `dd.mm.yyyy`; **обърнат** ред; маркери за липсващи (`n/a`, `-`, `няма`); празни колони; **дублиран** ред; редове-боклук отдолу (`Средно за 2023`, бележка); водещи интервали |
| `fuel_2024_raw.csv` | Седмични цени 2024 | **Различни** имена на колони; дати `yyyy-mm-dd`; **един отскок** (Бензин ≈ ×10 — изместена запетая); една липсваща стойност |
| `fuel_2025_raw.xlsx` | Седмични цени 2025 | Таблицата започва на **ред 4**; цените са в **EUR за ЛИТЪР**, а не за 1000 литра; празен ред по средата; ред-бележка отдолу; обърнат ред |
| `fuel_types_reference.xlsx` | Справочна таблица | За **обединяване (merge)**: човешки имена + кои горива влизат във финалната таблица |
| `fuel_prices_clean_TARGET.xlsx` | **Отговорникът** | Очакваният резултат + месечни средни + рецептата за почистване. Сравнете с него накрая. |

## Цел

Една таблица в **дълъг формат**:

```
Дата | Гориво | Цена (EUR/литър)
```

— сортирана, без дубликати, с единни мерни единици (EUR/литър), само трите автомобилни горива (Бензин А95, Дизел, LPG).

## Проверки (преди да кажете „готово")

- **Очаквани седмици:** 2023 = 51, 2024 = 53, 2025 = 52.
- **Редове в дългата таблица:** 465 = 3 горива × 156 седмици − 3 липсващи стойности.
- **Диапазон:** LPG ≈ 0,44–0,80; Бензин/Дизел ≈ 1,00–1,80 EUR/литър. Стойност извън това = грешка.
- Всяка промяна в броя редове трябва да е **обяснима** — нито един ред да не изчезва „случайно".

Пълната стъпка-по-стъпка рецепта е в лист **„Рецепта и проверки"** на `fuel_prices_clean_TARGET.xlsx`.
